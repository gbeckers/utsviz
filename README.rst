UTSVIZ
======

Visualization of uts signals.

Installation
------------

Install uts first.

Then install some additional conda packages

    $  conda install pandas matplotlib seaborn

You can do the above also in the Anaconda GUI, but you need the terminal for the next anyway:

To install the latest utsviz from Github: ::

    $ pip install git+https://github.com/gbeckers/utsviz@master
